import {MobileSearchField} from '@mattermost/compass-ui';

The Mobile Search Field is the sidebar-styled search control used on phones —
magnifier icon and placeholder on a translucent sidebar fill. Use it on the
[Mobile Search](/layouts/mobile-search) tab and in the
[Mobile Channel Sidebar](/patterns/mobile-channel-sidebar) Find channels row.

For desktop and light surfaces, prefer [Search Input](/components/search-input).

<Divider />

## Anatomy

- <Num>1</Num> **Leading icon** — Magnifier at 72% sidebar text.
- <Num>2</Num> **Input** — Body 200 field with sidebar-colored placeholder.

<AnatomyStage>
  <div style={{width:'100%',maxWidth:'360px',padding:'16px',background:'var(--sidebar-bg)',borderRadius:'8px'}}>
    <MobileSearchField placeholder="Search messages & files" />
  </div>
</AnatomyStage>

<Divider />

## Behavior

Pass a controlled `value` and `onChange` for typing. On Home, use the same
component with a Find channels placeholder so the control matches Search.

<Divider />

## Implementation

```tsx
<MobileSearchField
  value={query}
  onChange={(event) => setQuery(event.target.value)}
  placeholder="Find channels…"
/>
```

For props and variants, see the
[Mobile Search Field specimen page](/components/mobile-search-field/specimen).
