Radios let people pick exactly one option from a small, mutually exclusive
set — a workspace plan, a notification cadence, a default theme. Use a Radio
when the choices are few enough to show at once and the user benefits from
seeing every option side-by-side.

If you find yourself reaching for more than five or six options, switch to a
[Select](/components/select). If the choices aren't mutually
exclusive, use a [Checkbox](/components/checkbox) group instead.

<Divider />

## Anatomy

Every Radio is built from two parts that share one hit target.

<AnatomyStage style={{gap:'1.5rem',flexWrap:'wrap'}}>
  <Radio name="anatomy" defaultChecked>Notify me about every message</Radio>
</AnatomyStage>

- <Num>1</Num> **Selector** — the circle that fills with a dot when the option
  is chosen.
- <Num>2</Num> **Label** — the text that names the option. Click anywhere on
  the label or selector to toggle.

Selecting one Radio in a group automatically deselects whichever option was
chosen before. A Radio group should always have one option chosen by default —
don't ship a group in an indeterminate state.

## Sizes

Three sizes track the surrounding type. **Medium** is the default.

<div style={{display:'flex',gap:'1.5rem',flexWrap:'wrap',alignItems:'center',padding:'1rem 0'}}>
  <Radio size="Small" name="size-s" defaultChecked>Small (12px label)</Radio>
  <Radio size="Medium" name="size-m" defaultChecked>Medium (14px label)</Radio>
  <Radio size="Large" name="size-l" defaultChecked>Large (16px label)</Radio>
</div>

Pair Radio size with the size of the body type around it. Don't mix sizes
within a single group.

## States

Radios have an On and Off state, plus Disabled and Error.

<div style={{display:'flex',flexDirection:'column',gap:'0.75rem',padding:'1rem 0'}}>
  <Radio name="states-1">Off</Radio>
  <Radio name="states-2" defaultChecked>On</Radio>
  <Radio name="states-3" disabled>Disabled — Off</Radio>
  <Radio name="states-4" disabled defaultChecked>Disabled — On</Radio>
  <Radio name="states-5" valid={false}>Error — Off</Radio>
  <Radio name="states-6" valid={false} defaultChecked>Error — On</Radio>
</div>

Reach for the Error state when a group is required and the user has tried to
move on without choosing. Pair it with an
[error message](/components/error-message) below the group, never
on the option itself.
