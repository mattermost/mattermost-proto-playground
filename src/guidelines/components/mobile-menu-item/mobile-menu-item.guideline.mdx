The Mobile Menu Item is the touch-sized row used in iOS menus and bottom
sheets. It mirrors the desktop [Menu Item](/components/menu-item) structure —
label, optional leading and trailing visuals, secondary label, tag, and
destructive styling — with Body 200 type, larger icons, and no hover chrome.

Use the Specimen tab for the full Default / Active matrix.

Prefer desktop Menu Item in web menus and popovers. Prefer Mobile Menu Item in
mobile sheets and action lists.

## Anatomy

Four parts, same as desktop. Only the label is required.

  />
  <MobileMenuItem
    label="Notifications"
    secondaryLabel="All activity"
    secondaryLabelPosition="Inline"
    leadingVisual={<Icon glyph={<BellOutlineIcon />} size="20" />}
  />
  <MobileMenuItem
    label="Preferences"
    secondaryLabel="Theme, language, time zone"
    leadingVisual={<Icon glyph={<CogOutlineIcon />} size="20" />}
    trailingElement
    trailingVisual={<Icon glyph={<ChevronRightIcon />} size="20" />}
    divider
  />
</AnatomyStage>

- <Num>1</Num> **Label** — Body 200 action or option text. Required.
- <Num>2</Num> **Leading element** — optional 20px icon, avatar, or emoji.
- <Num>3</Num> **Secondary label** — optional metadata; Inline for short tags,
  Below (Stacked) for longer copy at Body 75 with secondary emphasis.
- <Num>4</Num> **Trailing element** — optional check, chevron, or badge.
- <Num>5</Num> **Divider** — optional hairline under the row for grouping.

## States

Mobile Menu Items do not use hover. Tap feedback and selection use the Active
fill.

| State | Use when |
| --- | --- |
| Default | Resting row. |
| Active | Row is pressed or selected (`active` prop or `:active`). |
| Focus | Keyboard focus has landed on the row. |
| Disabled | The action isn’t available right now. |

Active (non-destructive) uses button-bg at 8% over the channel background.
Destructive Active fills with danger color and inverts label and icons.

## Variants

### Destructive

Use for irreversible actions — leave a channel, delete, sign out. Pair with
confirmation where needed.

### Divider

Set `divider` when the row should show a bottom hairline between groups in a
sheet or menu list.
