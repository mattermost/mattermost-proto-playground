import { Scrollbar } from '@mattermost/compass-ui';

Scrollbars let people move through content that exceeds the viewport while
showing where they are in the larger whole. Compass uses a single, minimal
treatment — a transparent track with a thin, translucent thumb — so the
scrollbar reads as a position indicator first and a control second.

The thumb auto-hides when idle and reappears on hover or while scrolling, so
the scrollbar never competes with content for attention.

## Variants

| Option         | Values / behaviour                         | Use when                                                  |
| -------------- | ------------------------------------------ | --------------------------------------------------------- |
| Auto-hide      | On by default; thumb hides when idle       | Most product surfaces — keeps focus on content.           |
| Always visible | `alwaysVisible`                            | Demos, or when the scroll affordance must stay on screen. |
| Thumb colour   | `color="--sidebar-text-rgb"`               | Dark surfaces such as the channel sidebar.                |

A larger thumb means more of the content is visible. When the thumb fills the
track, hide the scrollbar — there's nothing to scroll.

## Use Scrollbar

Any scrolling region in a Compass surface should be rendered through the
`Scrollbar` component. It wraps `simplebar-react` and renders an overlay
scrollbar that floats above content — items always span the full width of
the container, and the thumb never reserves a gutter that pushes layout
around.

```tsx
import { Scrollbar } from '@mattermost/compass-ui';

<Scrollbar>
  <YourLongList />
</Scrollbar>
```

What you get:

- An overlay thumb that auto-hides when idle and reappears on hover or while
  scrolling.
- Cross-browser consistency — overlay behaviour, transitions, and theming
  match in Chrome, Safari, and Firefox.
- A translucent thumb tied to `--center-channel-color-rgb` at 24% alpha that
  bumps to 40% on hover, so the colour adapts to light and dark surfaces.
- A forwarded ref to the inner scrollable element for imperative
  `.scrollTo(...)` or read access to `.scrollTop`.

### Sizing

`Scrollbar` fills its parent by default. In a flex column, give the parent
`flex: 1; min-height: 0;` so the scroller can shrink correctly. For
fixed-height surfaces like menus, pass `style={{ maxHeight }}` directly on
the wrapper.

### Theming the thumb

On dark surfaces (e.g. the channel sidebar), pass `color` with the CSS
variable name to recolour the thumb against its background:

```tsx
<Scrollbar color="--sidebar-text-rgb">
  <ChannelList />
</Scrollbar>
```
