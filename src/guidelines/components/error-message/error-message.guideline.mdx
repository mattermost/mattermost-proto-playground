import { ErrorMessage } from '@mattermost/compass-ui';

Error Message is the inline red error line that appears below a form input
when validation fails. It pairs an alert glyph with a short, human-readable
explanation so the user can fix the field and move on.

<Divider />

## Anatomy

Two parts, sitting on a single line directly under the input they describe.

  style={{

  }}
>
  <ErrorMessage message="Enter a valid email address." />
  <ErrorMessage message="Password must be at least 12 characters." />
  <ErrorMessage message="Channel names can't contain spaces or special characters except dashes and underscores." />
</AnatomyStage>

- <Num>1</Num> **Icon** — `alert-circle-outline` at 12px, in
  `--color-danger`. Decorative; meaning is carried by the text.
- <Num>2</Num> **Message** — the explanation. One sentence, plain language,
  also in `--color-danger`.

<Divider />

## Content

- **Be specific.** _Email is required_ beats _This field is invalid._
- **Tell the user how to fix it.** _Password must be at least 12 characters._
- **Don't blame the user.** Describe what's wrong with the input, not what
  the user did wrong.
- **End with a period.** Error messages are sentences.

The message renders inside a `role="alert"` so screen readers announce it
when the field becomes invalid. Pair every error message with an `aria-invalid`
input and a programmatic association (`aria-describedby`).
