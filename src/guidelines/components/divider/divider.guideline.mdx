A Divider is a thin horizontal rule that separates content into related
groups. It does the lightest possible work — split a list, mark a
transition, give a layout breathing room — without competing for attention.

Use a Divider when whitespace alone isn't enough to communicate a break.
Reach for headings or section labels when groups need a name; the Divider
is the silent option.

## Anatomy

A single 1px rule centred in a small vertical container. The line uses a
low-contrast neutral color so it reads as structure, not as content.

## When to use

- **Between groups in a menu or list** — separating actions of different
  kinds (e.g. destructive vs. neutral).
- **Inside long forms** — marking the end of one section before another
  begins, when section headings would feel heavy-handed.
- **Between major sections of a guideline page** — as used throughout
  Compass docs.

<Divider />

## When not to use

- **Around every list item** — the row spacing is doing that job already.
- **As a decorative element** — if the line isn't separating two things,
  it's noise.
- **Inside a Card or Notice** — those components already define their own
  edges.
