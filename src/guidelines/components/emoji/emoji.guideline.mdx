Emoji is a compact, inline visual for conveying emotion, intent, or status —
on messages, in reactions, in pickers, or sprinkled through UI copy. The
component standardises sizing so native Unicode and custom workspace emoji
render at a consistent footprint alongside Icon.

<Divider />

## Anatomy

Emoji is a single-element component: a fixed-size inline frame that holds the
glyph. It mirrors the Icon container so the two compose cleanly side-by-side.

<AnatomyStage>
  <Emoji emoji="🎉" size="40" />
</AnatomyStage>

- <Num>1</Num> **Glyph** — the emoji character itself. Native Unicode or a
  custom workspace emoji.
- <Num>2</Num> **Container** — a square frame that scales the glyph to one of
  the standard icon sizes.

<Divider />

## Sizes

Emoji uses the same scale as Icon, so the two stay aligned wherever they
appear together — message reactions, menu items, autocomplete results.

| Size  | Use when                                                                              |
| ----- | ------------------------------------------------------------------------------------- |
| 10–16 | Inline with body text or in dense rows (autocomplete results, menu items).            |
| 20–24 | Default for reactions and message-adjacent UI.                                        |
| 28–40 | Picker grids and prominent reaction summaries.                                        |
| 52+   | Large, hero-style placements — empty states, celebration moments, onboarding visuals. |

Pick the size that matches the surrounding type and tap target. Don't mix
sizes within the same row.
