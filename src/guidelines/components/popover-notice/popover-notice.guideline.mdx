Popover Notice is a small overlay card that surfaces a transient message —
a tip, a confirmation, a warning — without taking over the screen. Think of
it as a [Section Notice](/components/section-notice) that floats:
shorter, dismissable, and gone in five seconds unless the user engages.

<Divider />

## Anatomy

An icon, a title, body content, optional actions, and a close button — all
on an `Elevation 3` rounded surface.

- <Num>1</Num> **Icon** — semantic glyph that mirrors the variant.
  Optional but recommended.
- <Num>2</Num> **Title** — the headline. Sentence case, six words or fewer.
- <Num>3</Num> **Body** — supporting copy. One or two short sentences.
- <Num>4</Num> **Actions** — optional. Up to two buttons; Primary right-most.
- <Num>5</Num> **Close** — optional `×` Icon Button in the top-right.
- <Num>6</Num> **Don't show again** — optional Checkbox below the body.

## Variants

Four semantic variants — pick by the meaning of the message, not by colour.

<DocUiEmbed>
  <div
    style={{
      display: 'flex',
      flexDirection: 'column',
      gap: '1rem',
      padding: '1rem',
      background: 'var(--center-channel-bg)',
      border: '1px solid rgba(var(--center-channel-color-rgb), 0.08)',
      borderRadius: '8px',
    }}
  >
    <PopoverNotice variant="info" title="Heads up" onClose={() => {}}>
      Threads now sync across devices.
    </PopoverNotice>
    <PopoverNotice variant="success" title="Channel created" onClose={() => {}}>
      `#design-reviews` is ready to go.
    </PopoverNotice>
    <PopoverNotice
      variant="warning"
      title="Almost out of seats"
      onClose={() => {}}
    >
      You have 2 seats left on this plan.
    </PopoverNotice>
    <PopoverNotice variant="danger" title="Connection lost" onClose={() => {}}>
      Reconnecting in a moment…
    </PopoverNotice>
  </div>
</DocUiEmbed>

| Variant  | Use when                                                                     |
| -------- | ---------------------------------------------------------------------------- |
| Info     | Default — a tip, a feature discovery, a neutral confirmation.                |
| Success  | Something completed and the user should know.                                |
| Warning  | Something might go wrong soon — quota nearly hit, version going stale.       |
| Danger   | Something has already broken and the user should act.                        |

Use semantic colour tokens — `--color-info`, `--color-success`,
`--color-warning`, `--color-danger` — never raw palette tokens.

## Actions

Action layouts mirror the rest of the system: zero, one, or two buttons,
Primary right-most. Reach for Primary only when there's a clear next step;
otherwise lean on Tertiary.

| Layout              | Use when                                                       |
| ------------------- | -------------------------------------------------------------- |
| No buttons          | Notice is informational — closes itself or via the `×`.        |
| Primary only        | One unambiguous action ("Got it", "Take a tour").              |
| Tertiary only       | Quiet acknowledgement ("Dismiss").                             |
| Tertiary + Primary  | Cancel + confirm pairings.                                     |

<Divider />

## Behavior

- **Auto-dismiss** — by default, the notice animates off after 5 seconds.
  Make this configurable per surface; disable auto-dismiss for warnings
  and danger variants.
- **Don't show again** — pair the optional Checkbox with a persistence key
  scoped to the message, not the variant.
- **Animation** — popover panel motion: scale 90% → 100% with fade in on
  entrance, the reverse on exit. Use `--ease-entrance` / `--ease-exit` and
  `--duration-quick`.
