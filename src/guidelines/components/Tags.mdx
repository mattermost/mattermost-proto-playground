Tags are compact labels for categories, status, or other identifying details.
They're scannable signal — a way to surface a small piece of metadata without
spending a sentence on it.

<Divider />

## Anatomy

<AnatomyStage style={{ gap: '0.5rem', flexWrap: 'wrap' }}>
  <Tags type="General">General</Tags>
  <Tags type="Info">Beta</Tags>
  <Tags type="Success">Active</Tags>

- <Num>1</Num> **Container** — the rounded surface that gives the tag its
  shape and semantic colour.
- <Num>2</Num> **Label** — short, descriptive text. One or two words is
  ideal.
- <Num>3</Num> **Leading icon** — optional; reinforces the meaning when an
  icon adds clarity (e.g. a lock for "Private").

## Types

Compass ships three families of tags. Each solves a different kind of "this
needs a label."

| Type           | Use for                                                                                                  |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| Label tag      | General classifications, status, or roles — Bot, Guest, New, Beta, Active, Deactivated.                  |
| Shortcut tag   | Keyboard shortcut hints inside menus, tooltips, and popovers (e.g. `⌘K`).                                |
| Highlight tag  | Inline emphasis on `@mentions`, search terms, and filter chips inside the message stream.                |

### Label tag — semantic types

The `Tags` component covers label tags directly. Pick a type that matches the
meaning, not the colour you want.

<div style={{ display: 'flex', gap: '0.5rem', flexWrap: 'wrap', alignItems: 'center' }}>
  <Tags type="General">General</Tags>
  <Tags type="Info">Info</Tags>
  <Tags type="Success">Success</Tags>
  <Tags type="Warning">Warning</Tags>
  <Tags type="Danger">Danger</Tags>
  <Tags type="Info Dim">Info Dim</Tags>
</div>

| Type      | Use when                                                                          |
| --------- | --------------------------------------------------------------------------------- |
| General   | Neutral classifications with no semantic state (Bot, Guest, role names).          |
| Info      | Informational callouts — Beta, New, Preview.                                      |
| Success   | Positive state — Active, Connected, Verified.                                     |
| Warning   | Needs attention but not blocking — Pending, Expiring soon.                        |
| Danger    | Error or destructive state — Failed, Expired, Deactivated.                        |
| Info Dim  | Quieter info treatment for dense surfaces where Info would feel too loud.         |

## Sizes

<div style={{ display: 'flex', gap: '0.5rem', flexWrap: 'wrap', alignItems: 'center' }}>
  <Tags size="X-Small" type="Info">X-Small</Tags>
  <Tags size="Small" type="Info">Small</Tags>
</div>

- **X-Small** — the default. Pairs with body copy and message headers.
- **Small** — for surfaces with larger type or when the tag carries an icon.

<Divider />

## Casing

<div style={{ display: 'flex', gap: '0.5rem', flexWrap: 'wrap', alignItems: 'center' }}>
  <Tags type="General">Title case</Tags>
  <Tags type="General" casing="All Caps">all caps</Tags>
</div>

Title case is the default. Use **All Caps** sparingly — it's reserved for
strong, persistent labels like role tags ("ENTERPRISE TEAM") that need to
read as eyebrow text rather than inline content.

<Divider />

## Content

- Keep labels to one or two words. Sentence case unless you've opted into All
  Caps for an eyebrow-style tag.
- A tag is a label, not a button. If users need to act on the thing the tag
  describes, give them an explicit control elsewhere.
- Don't stack three or more tags on a single row of metadata — pick the most
  important one.
