The More Unreads Banner is the small pill that floats inside the channel
sidebar to tell the user there are unread channels above or below the
current scroll position. One arrow, one label — clicking it scrolls to the
next unread.

<Divider />

## Anatomy

A pill with a directional arrow and a single-line label.

- <Num>1</Num> **Container** — pill surface. Sits at the top or bottom edge
  of the sidebar viewport.
- <Num>2</Num> **Arrow** — points up or down to match where the unreads are.
- <Num>3</Num> **Label** — `More unreads`. Don't customise.

| Size   | Use when                                                            |
| ------ | ------------------------------------------------------------------- |
| Small  | Compact sidebars (mobile, dense desktop).                           |
| Medium | Default — desktop sidebar.                                          |
| Large  | High-density variants and accessibility-leaning surfaces.           |

<Divider />

## States

Two interactive states. The banner is a button; clicking scrolls the sidebar
to the next unread channel.

| State    | Use when                                          |
| -------- | ------------------------------------------------- |
| Default  | At least one unread channel is off-screen.        |
| Hover    | Pointer is over the banner.                       |

The banner only renders when there is something to scroll to — hide it as
soon as all unreads are in view.
