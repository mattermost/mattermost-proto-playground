A Permalink Preview renders an inline card for a message that another
message links to. Sender, timestamp, body, and origin channel — enough
context to recognise the quoted message without leaving where you are.

<Divider />

## Anatomy

An Elevation 1 card with a [Message Header](/components/message-header)
on top, the message body in the middle, and an origin footer at the bottom.

- <Num>1</Num> **Container** — Elevation 1 rounded surface. Max width
  700px. Elevates to Elevation 2 on hover.
- <Num>2</Num> **Message Header** — author avatar, name, timestamp. Avatar
  displays inline (smaller than in the main stream).
- <Num>3</Num> **Body** — the quoted message text. Truncated past ~100px;
  show a `Show more` affordance to expand.
- <Num>4</Num> **Origin** — `Originally posted in ~Channel` footer that
  links back to the source.

The preview is a quotation, not a duplicate of the message. Reactions,
threads, and message actions don't appear inside it — those live with the
real message.

## Attachments

When the linked message contains attachments, render them inside the
preview body using the same components as the main stream — at reduced
density.

| Attachment    | Treatment                                                                |
| ------------- | ------------------------------------------------------------------------ |
| File cards    | Below the body in a responsive grid with 12px spacing.                   |
| Single image  | Max width 320px, max height 180px.                                       |
| Link previews | Render without the associated image; cap the description at two lines.  |

<Divider />

## Behavior

- **Click** anywhere on the preview to navigate to the original message.
- **Hover** raises the card to Elevation 2 and darkens the border, matching
  Link Preview.
- **Removable by the author.** A small dismiss control fades in on hover
  for the message author only — recipients can't remove a preview from
  someone else's message.
- **Truncation** kicks in past 100px of body height — append a `Show more`
  link that expands the preview in place.
- **Max width** is 700px, matching message-stream width.
