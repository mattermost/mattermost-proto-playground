The Channel Info Message Header names a channel (or section) and, when useful,
the team it belongs to. Use it above posts in Mentions and Saved lists, or as
section tabs at the top of a channel info panel.

For free-floating tabs elsewhere, reach for the Tabs component.

<Divider />

## Anatomy

- <Num>1</Num> **Channel label** — Pressable name of the source channel (or
  active section in a multi-tab panel).
- <Num>2</Num> **Divider** — Separates the channel label from the team when a
  team is shown.
- <Num>3</Num> **Team name** — Optional passive label after the divider. Hide
  it for single-team workspaces or when the team is already clear.

## Behavior

- In Mentions / Saved, pass `channelName` and optional `teamName` on each
  message (or via `MobileMessage`’s matching props).
- In a channel info panel with multiple sections, pass `tabs` instead and keep
  only one tab active at a time.
- The team name does not navigate — hide it when the context is unambiguous.
