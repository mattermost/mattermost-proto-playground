Message Actions is the floating toolbar that appears on a message when you
hover, tab, or long-press it. It bundles the most common per-message actions
— react, save, reply, more — into a small, context-aware row that hovers
above the post.

<Divider />

## Anatomy

A small `Elevation 1` surface holding a row of [Icon Buttons](/components/icon-button),
optionally preceded by quick-reaction emoji.

- <Num>1</Num> **Container** — `Elevation 1` rounded surface. Sits over the
  message it acts on.
- <Num>2</Num> **Quick reactions** — optional emoji shortcuts surfaced ahead
  of the action group.
- <Num>3</Num> **Action group** — Icon Buttons for save, AI, plugins, reply,
  and a kebab for the rest.

  <MessageActions type="Center Channel" />
</AnatomyStage>

The quick-reaction emojis are a shortcut, not a full picker — keep them
limited to the three most-used reactions plus an "add reaction" affordance.

## States

Message Actions follow the [Icon Button](/components/icon-button)
state model. The toolbar itself appears on hover and disappears when the
pointer leaves the message; keyboard focus pins it open.

| State    | Use when                                          |
| -------- | ------------------------------------------------- |
| Default  | The pointer is over a message; toolbar is shown.  |
| Hover    | The pointer is over a specific button.            |
| Active   | A button is being pressed.                        |
| Focused  | Keyboard focus lands on the toolbar.              |

## Variants

The action set varies by where the message lives. Don't reorder the buttons
between contexts — the muscle memory should hold.

| Variant         | Use when                                                       |
| --------------- | -------------------------------------------------------------- |
| Center Channel  | Default. Full action set plus quick reactions.                 |
| RHS             | Inside a thread or RHS — collapsed to the kebab to reduce noise. |
| Search Results  | Search snippets — adds a **Jump** affordance to navigate to the message in context. |

### Quick reactions toggle

Quick reactions can be turned off at the user or system level. When
collapsed reply threads is also off, the quick-reaction shortcut hides.
