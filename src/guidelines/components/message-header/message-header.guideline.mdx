The Message Header sits above every message body — username, optional bot or
guest tag, and timestamp. It's the byline of the conversation, so the rules
are tight: same parts, same order, every time.

<Divider />

## Anatomy

Three parts on a single row, left-aligned.

- <Num>1</Num> **Username** — display name. Bolder than the body. Clickable
  to open the [Profile Popover](/components/profile-popover).
- <Num>2</Num> **Tag** — optional `Bot` or `Guest` [Tag](/components/tag)
  inline with the name.
- <Num>3</Num> **Timestamp** — quiet, secondary-text colour. Click to copy a
  permalink to the message.

<AnatomyStage style={{flexDirection:'column',gap:'0.5rem',alignItems:'stretch'}}>
  <MessageHeader username="Leonard Riley" timestamp="10:43 AM" />
  <MessageHeader username="ReleaseBot" timestamp="9:12 AM" isBot botLabel="Bot" />
  <MessageHeader username="Maya Chen" timestamp="Yesterday" isBot botLabel="Guest" />
</AnatomyStage>

The header is fixed in order — username, tag, timestamp. Don't pad it with
status badges or extra metadata; that lives elsewhere on the message.

<Divider />

## Variants

| Variant   | Use when                                                              |
| --------- | --------------------------------------------------------------------- |
| Default   | Standard message from a member of the workspace.                      |
| Bot       | Posted by a bot account or webhook. Always show the `Bot` tag.        |
| Guest     | Posted by a guest user. Always show the `Guest` tag.                  |

Username weight is `var(--font-weight-semibold)` — never raise to bold (700).
