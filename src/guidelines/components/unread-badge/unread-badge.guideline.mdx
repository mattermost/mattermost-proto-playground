The Unread Badge is a small dot that signals "something's new here" without
specifying how much. Reach for it when the count would be noisy, distracting,
or simply isn't useful — a Team has unread channels, an icon button has a
new state, a tab has activity behind it.

## Contexts

The badge picks up its colour from the surface it sits on, so an unread dot
on a Team Avatar reads as a sidebar accent, while one on an Icon Button reads
as a foreground notification.

## When to use

- **Team Sidebar** — a Team has unread content, but no mentions.
- **Channel Sidebar** — a tab or filter has activity not yet shown.
- **Icon Buttons** — an action surface has new state behind it (e.g. saved
  posts, mentions list) without a meaningful count.

When a number **is** meaningful (mentions, replies, queued items), use a
**Mention Badge** instead.
