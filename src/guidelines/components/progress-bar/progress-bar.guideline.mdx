Progress Bar shows determinate progress through a wait state — an upload
finishing, a quota filling, an import running. Use it when the duration or
total is known; reach for [Spinner](/components/spinner) when
it isn't.

<Divider />

## Anatomy

Two parts — a track that defines the total, and a fill that grows from `0`
to `100%`.

- <Num>1</Num> **Track** — the surface behind the fill. Tells the user how
  much is left.
- <Num>2</Num> **Indicator** — the filled portion. Width follows the
  current value.

<AnatomyStage>
  <div style={{width:'320px'}}>
    <ProgressBar value={45} />
  </div>
</AnatomyStage>

Always pair the bar with a textual percentage or count nearby — the bar
gives the gestalt, the text gives the precision.

## States

Walk through the bar at the values you'd expect to render. The fill
animates smoothly from old to new — never snap.

| Value    | Use when                                                              |
| -------- | --------------------------------------------------------------------- |
| 0%       | The operation hasn't started or is queued.                            |
| 1–99%    | In progress. Animate the fill change.                                 |
| 100%     | Operation complete — hold briefly, then unmount or transition state.  |

## Variants

### Semantic colours

Turn on semantic colours when the bar represents a quota or threshold —
the fill shifts green → yellow → red as the value crosses 70% and 90%.
This is meaning, not decoration: only enable it when "more is worse".

<div style={{display:'flex',flexDirection:'column',gap:'0.75rem',padding:'1rem',background:'var(--center-channel-bg)',border:'1px solid rgba(var(--center-channel-color-rgb),0.08)',borderRadius:'8px',maxWidth:'320px'}}>
  <ProgressBar value={40} semanticColors />
  <ProgressBar value={75} semanticColors />
  <ProgressBar value={95} semanticColors />
</div>

| Range    | Colour                                                              |
| -------- | ------------------------------------------------------------------- |
| 0–69%    | `--color-success` — within budget.                                  |
| 70–89%   | `--color-warning` — getting close to the limit.                     |
| 90–100%  | `--color-danger` — at or past the limit.                            |

For "more is better" scenarios (download progress, file upload), keep the
default brand fill.
