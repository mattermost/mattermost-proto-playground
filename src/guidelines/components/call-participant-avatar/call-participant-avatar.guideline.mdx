The Call Participant Avatar represents a person — or a phone-in or
external-link participant — inside a Mattermost call. It carries the cues
that make a live call legible: who's talking, who's muted, who has their
hand up, who's a guest.

Use it anywhere participants are tiled or stacked: the call grid, the call
sidebar, popouts, and recording previews.

## Anatomy

- <Num>1</Num> **Image** — the user's avatar, cropped to a circle. Falls back
  to a silhouette for external links and a phone glyph for dial-in
  participants.
- <Num>2</Num> **Name label** — display name beneath the avatar.
- <Num>3</Num> **Mute badge** — a corner pill showing the current mic state.
  Required during a call.
- <Num>4</Num> **Talking ring** — animated outline that pulses while the
  participant is speaking.
- <Num>5</Num> **Reaction overlay** — floats an emoji above the avatar for the
  reaction's lifetime.
- <Num>6</Num> **Raised hand overlay** — pinned indicator that stays until the
  participant lowers their hand.
- <Num>7</Num> **Role labels** — small caps tag for HOST or EXTERNAL
  participants, beneath the name.

## Sizes

Four sizes match the surfaces calls render on — from full-bleed grid tiles
down to the call sidebar.

| Size   | Avatar | Use when                                                  |
| ------ | ------ | --------------------------------------------------------- |
| Large  | 120px  | Call popout grid, single-participant focus.               |
| Medium | 96px   | Multi-participant grid in the call window.                |
| Small  | 72px   | Compact grid; sidebar previews.                           |
| X-Small | 56px   | Roster lists; dense participant rows.                     |

## Participant kinds

The avatar handles three kinds of participants. Use the right kind so guests
and dial-ins are unambiguous.

| Kind            | Visual                                                              |
| --------------- | ------------------------------------------------------------------- |
| `user`          | The person's avatar image.                                          |
| `external-link` | Silhouette fallback. Pair with the EXTERNAL label.                  |
| `dial-in`       | Filled phone glyph on a green circle. Pair with the EXTERNAL label. |

## States and overlays

- **Hover / focus** — the avatar sits in a rounded tile with padding that scales
  by size. Hovering lightly highlights the tile on pointer devices; keyboard
  focus inside the tile uses the same highlight. By default, an overflow menu
  control (•••) appears in the top-right corner on hover or when focus is inside
  the tile. Pass `hostControls={false}` to hide it.
- **Muted / Unmuted** — always show the mic badge during a call so state is
  unambiguous; absence reads as "we don't know".
- **Talking** — pulse the ring only while audio is detected; remove
  immediately when speech stops.
- **Raised hand** — pinned, persistent. Doesn't auto-clear.
- **Reaction** — overlays for the reaction's lifetime, then fades.
