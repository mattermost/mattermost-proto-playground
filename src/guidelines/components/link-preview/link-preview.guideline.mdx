Link Previews appear under a message whenever it contains a URL with rich
metadata — a documentation page, a blog post, a product link. They give
the recipient enough context to decide whether to click without forcing
them to open the link cold.

<Divider />

## Anatomy

An Elevation 1 card stacking three text rows: site name, title, and
description.

<AnatomyStage>
  <LinkPreview onDismiss={() => {}} />
</AnatomyStage>

- <Num>1</Num> **Container** — bordered card at Elevation 1. Anchored to
  the left edge of the message body. Maximum width 700px.
- <Num>2</Num> **Site name** — small caption-size domain label that
  identifies the source.
- <Num>3</Num> **Title** — the link's primary headline. Limited to two
  lines; truncate with an ellipsis. Rendered in the link colour.
- <Num>4</Num> **Description** — short summary, also limited to two
  lines.
- <Num>5</Num> **Image preview** — optional. Render **Small** when the
  image aspect ratio is below 4:3, **Large** at or above 4:3.

<Divider />

## Variants

| Variant         | Use when                                                                              |
| --------------- | ------------------------------------------------------------------------------------- |
| Text only       | The destination provides title and description but no preview image.                  |
| Small image     | The destination supplies a portrait image (aspect ratio below 4:3).                   |
| Large image     | The destination supplies a landscape image at or above 4:3. Max 392 × 240px.          |

<Divider />

## Behaviour

- **The whole card is clickable.** Clicking anywhere on the preview opens
  the destination URL.
- **Removable by the author.** A small dismiss control fades in on hover
  for the message author only — recipients can't remove a preview from
  someone else's message.
- **One preview per link.** If a message contains multiple links with
  preview metadata, render a preview for each, stacked vertically.
- **Truncate, don't wrap.** Title and description are each capped at two
  lines. If a preview exceeds the limit, truncate with an ellipsis rather
  than letting the card grow tall.
