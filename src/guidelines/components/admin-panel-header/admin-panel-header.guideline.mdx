import { AdminPanelHeader } from '@mattermost/compass-ui';

Admin Panel Header is the titled rail for a System Console settings
section: optional leading icon, title with optional tags, subtitle, and trailing
controls. It is composed inside the
[`Admin Panel`](/patterns/admin-panel) pattern; it can also be
documented on its own when adjusting header anatomy or behaviour.

<Divider />

## Anatomy

    />
  </div>

- <Num>1</Num> **Leading icon** — optional circular slot; omit when the title alone is enough.
- <Num>2</Num> **Title row** — section name plus optional short tags (`Enterprise`, `Beta`).
- <Num>3</Num> **Subtitle** — one supporting line under the title when helpful.
- <Num>4</Num> **Trailing controls** — switch, sectional primary action, custom actions, or expand/collapse as needed.
