A Combobox lets people search and pick from a list of options — one value or
many. It looks like a [Select](/components/select) field, filters as you type,
and in multi-select mode shows chosen values as removable
[Chips](/components/chip).

Reach for a Combobox when the list is long enough to need typeahead, or when
people need to pick more than one value. Use a Select for shorter closed lists
with no search. Use a [Dropdown](/components/dropdown) for action menus that
don't capture a form value.

- <Num>1</Num> **Border** — the field surface; signals interactivity and
  state.
- <Num>2</Num> **Label** — optional floating label. Floats above the border
  once the field is focused, filled, or has chips.
- <Num>3</Num> **Leading icon** — optional. Reinforce the field's meaning.
- <Num>4</Num> **Value** — the chosen option label, or a row of chips when
  multi-select is on.
- <Num>5</Num> **Filter input** — type to narrow the list.
- <Num>6</Num> **Trailing icon** — chevron that flips while the list is open.
- <Num>7</Num> **Popover menu** — filtered options as a listbox.

## Single select

Type to filter, then choose one option. Selecting closes the list and shows
the chosen label in the field.

## Multi select

With `multiple`, each choice becomes a removable chip inside the field.
Selecting an option closes the list. Backspace on an empty filter removes
the last chip.

<div style={{maxWidth:'360px',padding:'1rem 0'}}>
  <Combobox
    label="Invite people"
    placeholder="Search people…"
    multiple
    options={PEOPLE_OPTIONS}
    defaultValue={['emma', 'arjun']}
  />
</div>

## States

Comboboxes share their state model with the rest of the input family.

| State    | What it shows                                                       |
| -------- | ------------------------------------------------------------------- |
| Default  | Empty or placeholder text.                                          |
| Focus    | Blue ring; filter input is active.                                  |
| Filled   | A value or chips are present; the floating label settles above.     |
| Open     | The popover list is visible; the chevron flips.                     |
| Disabled | Greyed out; non-interactive.                                        |
| Invalid  | Red border; pair with an inline error message below.                |

## Keyboard

| Key        | Action                                              |
| ---------- | --------------------------------------------------- |
| ↓ / ↑      | Open the list (if closed) and move the highlight.   |
| Enter      | Select the highlighted option.                      |
| Escape     | Close the list.                                     |
| Home / End | Jump to the first or last enabled option.           |
| Backspace  | In multi-select with an empty filter, remove the last chip. |
| Tab        | Close the list and move focus onward.               |
