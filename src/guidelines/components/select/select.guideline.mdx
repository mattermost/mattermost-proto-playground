A Select lets people pick one value from a longer list — a country, a team,
a default channel — inside a form or modal. It looks like an input and opens
a popover menu of options styled like other Compass menus.

Reach for a Select when the list of options is too long for a
[Radio](/components/radio) group but the choice is still
single-select. For action menus that don't capture a value, use a
[Dropdown](/components/dropdown) instead.

- <Num>1</Num> **Border** — the field surface; signals interactivity and
  state.
- <Num>2</Num> **Label** — optional floating label. Floats above the border
  once a value is set.
- <Num>3</Num> **Leading icon** — optional. Reinforce the field's meaning
  (e.g. a globe for a region picker).
- <Num>4</Num> **Value** — the currently chosen option, shown inside the
  field.
- <Num>5</Num> **Trailing icon** — always a chevron, signalling that the
  field opens a list.
- <Num>6</Num> **Popover menu** — the list of options, shown on click.

## States

Selects share their state model with the rest of the input family.

| State    | What it shows                                                          |
| -------- | ---------------------------------------------------------------------- |
| Default  | Empty or placeholder text.                                             |
| Hover    | Slight border tint to invite interaction.                              |
| Focus    | Blue ring around the border; keyboard interactions work.               |
| Filled   | A value is chosen; the floating label settles above the field.        |
| Disabled | Greyed out; non-interactive; not announced as form control.            |
| Invalid  | Red border; pair with an inline error message below.                   |
| Open     | The popover menu is visible; the chevron flips.                        |

## Variants

Four boolean axes compose Select's variant matrix:

- **Leading icon** — reinforce meaning when the field's purpose isn't
  obvious from the label alone.
- **Avatar** — for choosing a person, render an avatar in the leading slot.
- **Border** — borderless variant for inline contexts (e.g. table cells).
- **Trailing icon** — always present in the standard variant; remove only on
  borderless inline use.

## Implementation

Placeholder hint text on the empty field may sit at **64%** opacity on the
center-channel color — an intentional exception to the usual **72%** text
floor. Selected values and labels still meet the standard floor. Disabled
Selects may dim as low as **40%** opacity (often **56%** on the control
surface).
