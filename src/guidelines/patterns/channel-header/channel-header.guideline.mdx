The Channel Header is the overarching header above the main content area. It is
composed of smaller pieces — channel identity, stats, channel metadata, plugin
slots, and global actions — and supports multiple channel types and interaction
states.

In the full product this pattern spans everything from the channel title through
global shortcuts on the right. The Specimen tab focuses on the
layout variants (identity row, favorites, stats,
description, call, and channel info); search, mentions, saved posts, help, and
plugin icons are specified below so implementations stay aligned with Compass
even when those slots are composed elsewhere in the app shell.

## Anatomy

The Channel Header brings together the following elements, generally ordered
from channel identity on the left toward global utilities on the right.

<ChannelHeaderAnatomyStage />

- <Num>1</Num> **Favorite icon button** — Toggle that marks the channel as a
  favorite.
- <Num>2</Num> **Channel name and dropdown** — Shows the channel display name and
  opens a dropdown with channel configuration options.
- <Num>3</Num> **Members icon button (with count)** — Shows how many members
  belong to the channel. Opens the Channel Members right-hand sidebar with
  the member list and a path to manage members.
- <Num>4</Num> **Pinned icon button (with count)** — Shows how many messages are
  pinned in the channel. Opens the right-hand sidebar with all
  pinned messages for that channel.
- <Num>5</Num> **Channel Files icon button** — Shows only if the channel has files in it. Clicking opens the right-hand sidebar with a view of recent files in the channel.
- <Num>6</Num> **Channel header info** — Surfaces the channel header description (truncated). On hover the full description shows in a popover.
- <Num>7</Num> **Start call button** — Begins an audio call in the channel.
- <Num>8</Num> **Channel info icon button** — Opens the channel info right-hand sidebar.

## Types

### Standard Channel Header

<Preview caption="Standard channel header">
  <div style={{ width: '100%' }}>
    <ChannelHeader
      type="Channel"
      name="UX Design"
      memberCount={48}
      pinnedCount={3}
      description="Design critiques, specs, and Compass references."
    />
  </div>
</Preview>

Used for public and private channels. This is the baseline layout: full title
treatment, favorites, members and pins where applicable, channel info, plugins,
search, mentions, saved posts, and help.

### Direct Message header

<Preview caption="Direct message header">
  <div style={{ width: '100%' }}>
    <ChannelHeader
      type="DM"
      name="Aiko Tan"
      avatarSrc={avatarAikoTan}
      avatarStatus
      pinnedCount={1}
    />
  </div>
</Preview>

Matches the Standard header with these changes:

- Shows the other person’s display name instead of a channel name.
- Adds a status badge and label next to the channel header info.
- Omits the Members icon button.

The Specimen tab in this playground also includes Threads and Drafts headers —
narrower layouts for those contexts — implemented as additional `ChannelHeader`
variants.

## States

- Channel header info — hover popover — Hovering the info affordance reveals the
  richer description and links without leaving the channel.
- Icon button — hover tooltip — Toolbar icons expose concise labels on hover so
  intent stays clear at a glance.
- Icon button — active / pressed — Toggled actions (for example, info pinned open)
  use the active visual treatment until dismissed.
