Text is an integral part of any user interface, so it's important that all
typographic elements are designed for legibility and consistency. This section
defines the typographic style and usage guidelines.

<Divider />

## Typefaces

Compass uses **Metropolis** and **Open Sans** as its primary typefaces. Together
they cover everything from chrome-level labels and body copy to large display
headings.

Use Metropolis for large headings where a more distinctive voice helps create
structure. Use Open Sans for body copy, compact labels, dense product surfaces,
and smaller headings where legibility matters more than display character.

## Type scale

A type scale ensures different sizes of text work together harmoniously. Compass
uses a **1.125 ratio** — each step is multiplied or divided by 1.125 from the
previous size, then rounded.

The base font size for the Mattermost web app is **14px**.

### Line heights

Body copy line heights generally use a multiplier of **1.5** based on the font
size, with adjustments so baselines fall on a 4px grid.

Heading line heights generally use a multiplier of **1.3** based on the font
size, with adjustments for the 4px grid. Smaller headings also use the 1.5
multiplier.

Use the Specimen tab when you need the exact step values, line heights, token
names, or copy-ready CSS.

## Headings

Headings are generally used in the **semibold** weight, but can also use regular
or light weights when typographic contrast is needed. Bold weights can be used
in special cases to help legibility for the smallest headings.

Choose heading levels by hierarchy, not by visual preference alone. A page title,
section title, panel title, and row label should each occupy a clear step in the
information structure. Avoid skipping to oversized headings just to create
spacing; use layout spacing for that.

## Body copy

Body copy always uses the **regular** weight. Where emphasis is needed, the
**semibold** weight can be used. In special cases, bold weights can be used to
help legibility with the smallest body sizes.

Use body copy for content that users need to read or scan. Use smaller steps for
metadata, helper text, dense controls, and secondary labels. Preserve contrast by
changing weight or color sparingly; too many typographic treatments make a dense
interface harder to scan.

## Margins

Margin refers to the space surrounding a text element. The values below are
defaults that produce a good typographic starting point — they can be overridden
when a specific layout requires it.

### Collapsing margins

Top and bottom margins of adjacent text elements collapse into a single margin
equal to the **larger** of the two. Don't double up by setting both — pick one
direction and let the other element drive the gap.

For product UI, prefer explicit layout spacing around components and patterns.
Use text margins as a default for prose-like content, not as a substitute for
component layout.
