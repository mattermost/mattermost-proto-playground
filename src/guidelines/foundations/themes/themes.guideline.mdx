Themes let users tailor the Mattermost interface to their environment and
preferences while keeping the product visually coherent. A theme remaps a
small set of role-based color tokens — sidebar, center channel, buttons,
interactions, status — so every component built on those tokens adapts
automatically.

Themes are applied via a `data-theme` attribute on the root `<html>`
element, and the user's selection persists across sessions.

## How themes work

Themes are a layer of **role-based tokens** that sit on top of the
foundation palette. Foundation tokens (e.g. `--color-blue-500`) describe
*what a color is*; theme tokens (e.g. `--button-bg`) describe *what role a
color plays in the interface*. Each theme reassigns role tokens to
appropriate palette values for that look.

Every theme token also exposes an `-rgb` counterpart for use inside
`rgba()` so transparency stays theme-aware:

```scss
// Solid fill — adapts to whatever the active theme defines.
background-color: var(--button-bg);

// Translucent fill — use the -rgb variant inside rgba().
background-color: rgba(var(--button-bg-rgb), 0.16);
```

## Authoring components for themes

Components must work on every theme without per-theme overrides. Follow
these rules.

**Use theme tokens for product UI.** Reach for role-based theme tokens
over raw palette tokens. Palette tokens are appropriate inside
foundation-level demos, illustrations, or data visualizations where the
color is intentional and not theme-dependent.

**Use the `-rgb` variant inside `rgba()`.** The variant lets translucency
inherit the theme's resolved color. Never wrap a `var(--token)` reference
itself in `rgba()`.

**Don't hard-code hex values.** Anywhere a theme could change the surface
beneath your component, a hard-coded color will break contrast on at least
one theme.

**Test on dark themes.** Borders, dividers, and translucent overlays often
look correct on Denim but disappear on Indigo or Onyx. Check every new
component on at least one light and one dark theme before merging.

**Lean on `--center-channel-color-rgb`** for borders, dividers, and
subtle backgrounds inside the center channel. A low-alpha rgba on the
center channel text color produces a separator that adapts to every theme:

```scss
border-bottom: 1px solid rgba(var(--center-channel-color-rgb), 0.08);
```
