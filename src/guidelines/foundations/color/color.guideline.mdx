## Semantic Colors

Semantic colors help users identify status, see critical information, locate help, and understand the next steps they need to take.

In product, fixed intent colors share Mattermost's `--semantic-color-*` names; `--color-info|success|warning|danger` wrap those values. Themeable error and destructive surfaces use the error-text theme token (with semantic danger as fallback). Presence (online / away / DND) uses the status indicator theme tokens — see [Themes](/foundations/themes).

## Tokens and implementation

Each shade is exposed as a CSS custom property (e.g. `--color-blue-500`) along with its `-rgb` counterpart for use inside `rgba()`. For the full token list, copy-ready values, and usage examples, see the [Color specimen page](/foundations/color/specimen).

## Themes

Most product surfaces should reach for **theme-aware tokens** rather than raw palette values, so the interface adapts across light, dark, and custom themes. See the [Themes guideline](/foundations/themes) for how themes work and which tokens to use when authoring new components.
