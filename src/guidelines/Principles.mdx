# Principles

The Mattermost design system rests on a small set of principles. Each one
exists so designers and engineers can resolve ambiguity without escalating.

## Clarity over cleverness

Prefer the obvious solution. A novel pattern carries a teaching cost for
every person who encounters it; reach for one only when an existing pattern
genuinely fails the user.

## Consistency is a feature

Two screens that solve similar problems should look and behave alike. Every
inconsistency is a small bet that _this_ situation is special — most are not.

## Defaults serve the median

The default state should serve the most common case well. Power-user
affordances live one click deeper, not on the surface.
